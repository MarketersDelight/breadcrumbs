# Breadcrumbs tests

These tests use the Marketers Delight theme's isolated WordPress stubs. Clone or install the theme at `wp-content/themes/marketers-delight` and this Drop-in at `wp-content/md-dropins/breadcrumbs`, then run `./tests/run.sh --do-not-cache-result` from the Breadcrumbs directory. The bundled theme PHPUnit runner requires PHP 8.1 or newer. No WordPress database is needed.
